# Зелений вибір

Навчальний MVP-вебсайт екологічної платформи на чистому HTML, CSS і JavaScript. Проєкт пояснює сортування відходів, екологічні звички та повторне використання речей.

## Технології
- HTML5 і семантична розмітка
- Tailwind CSS через CDN
- Чистий JavaScript ES6+
- Swiper через CDN
- `data/data.json` для mock-даних
- localStorage для теми і останніх результатів
- Vercel для статичного хостинга

## Функції
- адаптивне мобільне меню і dark/light режим;
- пошук і фільтри довідника сортування;
- тест із 10 запитаннями та трьома рівнями результату;
- персональний екочекліст із перевіркою даних;
- формою з клієнтською валідацією та доступною модалкою;
- власні SVG-зображення;
- SEO, Open Graph, favicon, robots і sitemap.

## Локальний запуск
Найпростіше відкрийте папку проєкту у VS Code, встановіть розширення **Live Server**, натисніть `Go Live` і виберіть `index.html`. Важливо запускати через HTTP-сервер: `fetch("data/data.json")` не працює коректно через `file://`.

## Деплой на Vercel
Додайте у налаштуваннях репозиторію секрети `VERCEL_TOKEN`, `VERCEL_ORG_ID` і `VERCEL_PROJECT_ID`. Workflow `.github/workflows/deploy.yml` перевіряє HTML та розгортає сайт після push у `main`.
